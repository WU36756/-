# 评委使用说明（一页）

## 1. 打开
浏览器访问：`https://你的域名`
页面会要求输入**访问码**（由管理员提供），输入后进入。
每个浏览器独立一份数据，初始为演示资料，不会看到别人的记录。

## 2. 两种用法，任选

### A. 最快：直接用 Mock（不需要 key）
模型下拉框选 **Mock · 不耗额度**，直接输入问题。
适合先看流程和界面，秒回。

### B. 用你自己的模型 key
1. 点左上角 **⚙ 自定义接口**；
2. 地址和模型已预填（也可改成你自己的 OpenAI 兼容接口）；
3. 粘贴你的 API Key；
4. 点 **测试连接并激活**，看到“连接成功”即可；
5. 关闭弹窗，正常提问。

> 没有 key、或测试失败：直接关掉弹窗，用 Mock 体验，不影响流程展示。

## 3. 第一次提问要等
真实模型首轮约 **1–2 分钟**（多 Agent 串行：分诊 → 辨证 → 检索 → 撰写 → 审查）。
页面会显示“正在生成建议… N 秒”，**不要刷新、不要重复点发送**。

## 4. 可以问什么
- 身体：`发烧，咽喉痛，有点怕冷`、`咳嗽三天有黄痰`、`胃胀反酸`、`崴脚了脚踝肿了`
- 心理：直接输入 `最近压力大，睡不着`
- 饮食：直接输入 `炸鸡健康吗`、`减脂早餐怎么吃`
- 平台会自动判断身体/心理/饮食，不需要切换专家

## 5. 出问题怎么办
- 页面空白/按钮没反应：刷新一次（Ctrl+F5）；
- 提示“已用内置演示答案”：说明模型 key 没连通，按第 2 步重新测试，或继续用 Mock；
- 一直转圈超过 3 分钟：刷新后换 Mock 演示；
- 不要点「演示数据重置」（已对公网关闭）。

## 6. 边界
