# 设计说明（M1）

## 安全边界

1. 输出定位为"循证信息 + 就医建议"，不做诊断、不开处方。
2. 红旗症状（胸痛、呼吸困难、意识改变、抽搐、大出血、呕血/黑便、孕产异常、婴儿高热等）→ 报告首条即为"立即就医/急救"，不进入用药信息。
3. 用药剂量只允许引用说明书原文，并标注来源与检索时间。
4. 特殊人群（儿童、孕妇、哺乳、慢病、肝肾不全）不给剂量，转就医。
5. 证据不足时明确输出"证据不足"，不臆测。
6. 报告固定包含免责声明与局限性。

## 多 Agent 设计

| Agent | M1 状态 | 职责 |
|---|---|---|
| 分诊 | 已实现（确定性规则） | 红旗识别、就医级别 |
| 检索 ×N | 已实现（3 个工具，串行；M2 并行） | PubMed / openFDA / 白名单网页 |
| 证据评估 | 简化实现 | 去重、按来源分级、截断 |
| 报告生成 | 已实现（LLM / 模板） | 结构化 Markdown，带 [n] 引用 |
| 安全审查 | 已实现（确定性检查） | 引用核对、免责声明、红旗、剂量引用、越界措辞；不通过回写 |
| Self-Loop | M2 | 审查不通过 → 修复重写，最多 2 轮 |

## 知识库规模

- 中药：100 条（42 个 OTC 中成药 + 58 味中药材/饮片）
- 西药：20 种常见 OTC（中文适应症/用法/禁忌/参考价）
- 权威指南：24 个 NHS 页面，附中文要点；来源原文可点开查看

## 数据契约

```json
{
  "symptoms": "...",
  "triage": {"urgent": false, "reasons": []},
  "evidence": [{"source": "pubmed", "title": "...", "url": "...", "snippet": "...", "retrieved_at": "..."}],
  "report_markdown": "...",
  "review": {"passed": true, "findings": []},
  "provider": "mock|deepseek",
  "generated_at": "..."
}
```

## 验收（M1）

- `uv run pytest` 全绿；
- mock 模式能产出带引用与免责声明的报告；
- 红旗症状输入直接产出"立即就医"报告且不含用药建议；
- API `/api/analyze` 可用。
