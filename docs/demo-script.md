# 3 分钟演示脚本（现场版）

> 目标：评委在 3 分钟内看到"多 Agent 的差异"，而不是只看一个聊天框。
> 准备：打开 `http://127.0.0.1:8100`；模型保持 **Mock**（不耗 token、断网可用）；提前点一次"重置演示数据"。

## 演示前 30 秒检查

1. 服务在跑：页面能打开；
2. 模型选择 **Mock**；
3. 个人资料是干净状态（30 岁女性、无过敏、2 条药）；
4. 浏览器缩放 100%，窗口最大化；
5. 轨迹抽屉、对比实验、消融实验三个入口位置记住。

---

## 0:00–0:15 开场

**操作**：停在首页，鼠标划过左侧栏。

**台词**：
> 这是我们的健康助手。它不是一个模型在回答，而是一支有分工的 Agent 团队：分诊、辨证、查知识库、并行检索、撰写、安全审查。右边这个"轨迹"会记录每一步。

---

## 0:15–1:00 问诊主流程

**输入**（直接粘贴）：

```
发烧，咽喉痛，有点怕冷，两天了
```

**操作**：
1. 发送后不要急着往下滚，先让评委看到步骤条：`红旗分诊 → 辨证 → 中成药匹配 → 并行取证 → 工具调用 → 安全审查`；
2. 答案出来后，指一下：首选中药（中成药 + 药材 + 备用西药）、用法、禁忌、来源数量；
3. 点开底部 **"轨迹"** 按钮，展示每一步的中文摘要（"检索 PubMed / openFDA / NHS-WHO-CDC"、"安全审查：0 个问题"）。

**台词**：
> 同样一句话，单 Agent 会直接给一段话；我们会先分诊排除红旗，再辨证，查 138 条中药库，三路并行检索，最后过一遍安全审查。这里能看到每一步谁做的、花了多久、拿到几条证据。

---

## 1:00–1:25 对比实验：多 Agent 到底强在哪

**操作**：左侧 **"对比实验"** → 展示表格。

**台词**：
> 我们跑了 4 个真实用例的对照。单 Agent 平均 5 秒、676 token，但引用可核验率是 0，安全审查平均 4.25 个问题；多 Agent 慢很多、贵很多，但引用可核验率 100%，审查问题 0，4 个回答都带免责声明。健康场景里，我们选择用速度换可信。

**操作**：接着打开 **"消融实验"**。

**台词**：
> 每个 Agent 是不是必需？去掉知识库，可选药物从 7 个变成 0；去掉并行检索，耗时从 1.6 秒涨到 4 秒。审查在模板上是 0 问题，但我们注入一条"布洛芬一次 800 毫克"的错误剂量，它能抓出来。

---

## 1:25–1:50 心理支持

**输入**：

```
最近压力大，睡不着，脑子停不下来
```

**操作**：展示心理支持卡片、应对建议、求助资源。

**台词**：
> 情绪问题走的是另一条入口。它会给可执行的建议和求助资源；如果是高风险表达，会直接给热线和就医提示，而不是继续讲道理。

> 如时间允许，可补一句："混合意图比如'心情不好，失眠'，它会先反问你想问哪方面，而不是硬猜。"

---



## 2:20–2:50 我的药 + 康复计划

**操作**：
1. 左侧 **"我的药"** → 点一次"打卡一次" → 龙珠点亮、库存 -1；
2. 左侧 **"康复计划"** → 展示今日打卡、症状评分滑杆、趋势曲线、第 7 天自适应说明。

**台词**：
> 建议不是终点。药可以设提醒、打卡、看库存和有效期；康复计划每天打分，第 7 天按趋势决定是延长一周还是建议复诊。

---

## 2:50–3:00 收尾

**操作**：回到对话页。

**台词**：
> 一句话总结：每个结论有来源，每个回答过审查，每一步可复盘。平台本地一键运行，断网也能演示。

---

## 断网/翻车预案

| 情况 | 处理 |
|---|---|
| 外网检索超时 | 正常，轨迹会标"这次没取到内容"；继续讲本地知识库与审查 |
| DeepSeek 慢/无 Key | 保持 Mock，强调"演示模式零 token、可离线" |
| 页面白屏 | 刷新；仍异常则重启 `sudo systemctl restart health-panel.service` |
| 图片识别失败 | 换一张清晰的单食物图；或直接讲食物库检索 |
| 数据脏 | 个人资料 → **重置演示数据** → 刷新 |
